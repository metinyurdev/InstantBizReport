## 📌 Project Overview

**InstantBizReport** is a secure reporting platform for modern businesses. It allows users to instantly visualize operational data from key departments:

- 💰 **Finance**
- 📈 **Sales**
- 🧑‍💼 **Human Resources**

The goal: **make business insights accessible, fast, and interactive.**

---

## 🧠 Key Features

| ✅ Feature               | 🔎 Description |
|-------------------------|----------------|
| 🔐 OAuth2 Login         | Secure authentication with JWT |
| 🗂️ Sidebar Navigation   | Select report category: Finance / Sales / HR |
| 📊 Dynamic Charts       | Choose between **bar** or **pie** charts |
| 📄 Export as PDF        | Download tables and visualizations as PDF |
| 🧮 Tabular Data Views   | Display formatted DataFrames for quick insights |
| 🛡️ Hashed Passwords     | Stored securely in MySQL using bcrypt |
